# Ausadhi

Ausadhi is a hyper-local medicine availability and stock verification tracker for Nepal.

## Overview

The project is designed to help users work with medicine availability and stock information through a web application with a React frontend and an Express backend.

## Tech Stack

- React
- TypeScript
- Vite
- Express
- MongoDB with Mongoose
- JSON Web Tokens
- bcryptjs
- Tailwind CSS
- Google GenAI
- XLSX data handling

## Development

```bash
npm install
npm run dev
```

The development server is started through `tsx server.ts`.

## Production Build

```bash
npm run build
npm start
```

## Configuration

Use environment variables for application configuration and credentials. Do not commit real secrets, database credentials, tokens, or API keys.

## Status

This is an active application project. Authentication, database integration, file handling, and AI-related functionality should be tested carefully as the project develops.
